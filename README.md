## 系統設計

### 作答（網站 `quiz.html`）
- GitHub Pages 網站，手機、電腦都能用。
- 每題記錄：**答案**、**作答時間**、**把握程度**（確定 / 猜的 / 不會）。
- 交卷後顯示**簡易解**；完整檢討回到 Claude Code。
- 結果透過 GitHub API 自動存進 `results/`（需在網站設定一次 GitHub token）。

### 出題比例（每份平日題目約 25～30 題）
| 比例 | 內容 |
|---|---|
| 50% | 盲點題：針對近期錯誤，**換一種方式出** |
| 20% | 複習題：1～2 週前的舊盲點 |
| 30% | 新範圍：依 [文法進度表](notes/grammar-syllabus.md) 推進 |

盲點**連續答對 3 次**就算已解決，移出盲點清單，只留在 flashcard 繼續複習。

### Flashcard（網站 `cards.html`）
- 內建間隔重複（SRS），進度同步到 `progress/srs.json`。
- 三種卡片：
  - **單字（讀音）**：漢字 → 讀音、中文意思、例句
  - **單字（寫法）**：讀音加例句 → 漢字、易混淆字
  - **文法**：例句挖空 → 文法、意思、接續、**易混淆文法比較**
- 自評「忘了 / 模糊 / 記得」決定下次出現時間；**每天新卡片上限 20 張**。

### 聽解（第 4 週起）
- Claude 寫腳本（課題理解、重點理解、概要理解、即時應答、統合理解）。
- 用 `edge-tts` 產生 Nanami（女）和 Keita（男）的對話 MP3。若 edge-tts 失效，改用瀏覽器朗讀。

### 語言
- 題目：100% 日文。
- 解說：繁體中文為主，文法語感附日文原文。第 7 週後可改成日文解說。

### 官方題本
- 放在本機的 `reference/`，**不上傳到 GitHub**（見 `.gitignore`）。
- 公開 repo 只放原創題目。

## 每日節奏

| 時間 | 做什麼 | 在哪裡 |
|---|---|---|
| 通勤或空檔 | flashcard ＋ 當天的題目 | 手機 |
| 晚上 | 在 Claude Code 說「**檢討**」→ 報告 → 一題一題問為什麼選這個 → 更新盲點和 flashcard → 產生明天的題目 | 電腦 |
| 週末一天 | 計時的週模考 ＋ 大檢討 ＋ 下週計畫 | 電腦或手機 |

隨時保有 **2 份備用題目**，某天沒辦法檢討也不會斷掉。

## 檢討流程
1. **報告**：分數、各題型正確率、耗時過長的題目、「猜對」的題目。
2. **逐題討論**：只看答錯的題目和猜對的題目；先問「當時為什麼選這個」，再講解。
3. **產生下一輪**：更新 `notes/blindspots.json`、新增 flashcard、出明天的題目並推送。
