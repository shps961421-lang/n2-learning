## 每日題目：短小、A／B 交替

> 2026/10/2 調整：原本一份 25～30 題太長，做到一半就會分心，所以改成短測驗。

| | **A：語言知識** | **B：讀解** |
|---|---|---|
| 內容 | 單字 8 題 ＋ 文法 7 題 | 短文 1 篇 ＋ 中文 1 篇 |
| 份量 | **15 題，約 15 分鐘** | **2 篇（6～8 題），約 20 分鐘** |

- **一天先做 1 份**，原則上 A、B 交替。首頁會標示「建議下一份」。
- 網站上**隨時保有 A、B 各 2 份**還沒做的題目，想多做一份也有題目可以做。
- **flashcard 每天都做**，不跟著 A／B 輪替。
- 新文法**由 flashcard 教**（卡片背面有意思、接續和容易混淆的比較），A 日的文法題**負責考**已經學過的文法。

### 加量標準（每週日檢查，第一次 10/11）
交卷時會問「這次專注度如何？」（很專注 / 還好 / 後半段分心）。
- **7 天中有 5 天以上完成題目，而且大部分沒有分心** → 改成一天 **A、B 各 1 份**。
- 沒達到 → 維持原本的量，下週再檢查一次。

### 週模考：逐步拉長，練習耐力
| 週次 | 長度 |
|---|---|
| 第 1 週 | 診斷測驗代替 |
| 第 2 週 | 約 30 分鐘（約 25 題） |
| 第 3–4 週 | 約 50 分鐘 |
| 第 5 週 | 約 75 分鐘 |
| 第 6 週起 | 105 分鐘全長（第 6、8 週是官方題本） |

如果拉長之後分心得很嚴重，下週就維持原本的長度。

## 系統設計

### 作答（網站 `quiz.html`）
- GitHub Pages 網站，手機、電腦都能用。
- 每題記錄：**答案**、**作答時間**、**把握程度**（確定 / 猜的 / 不會）；交卷時記錄**專注度**。
- 交卷後顯示**簡易解**；完整檢討回到 Claude Code。
- 結果透過 GitHub API 自動存進 `results/`（需在網站設定一次 GitHub token）。

### Flashcard（網站 `cards.html`）
- 內建間隔重複（SRS），進度同步到 `progress/srs.json`。
- 三種卡片：**單字（讀音）**、**單字（寫法）**、**文法**（挖空，附容易混淆的比較）。
- 自評「忘了 / 模糊 / 記得」決定下次出現時間；**每天新卡片上限 20 張**。

## 檢討流程
1. **報告**：分數、各題型正確率、耗時過長的題目、「猜對」的題目、專注度。
2. **逐題討論**：只看答錯的題目和猜對的題目；先問「當時為什麼選這個」，再講解。
3. **產生下一輪**：更新 `notes/blindspots.json`、新增 flashcard、補足 A／B 各 2 份題目並推送。
